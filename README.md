Automated updates of the WinGet package of
[Freelens](https://github.com/freelensapp/freelens).

The manifests are generated here and submitted to
[microsoft/winget-pkgs](https://github.com/microsoft/winget-pkgs) through the
fork [freelensapp/winget-pkgs](https://github.com/freelensapp/winget-pkgs).

Install:

```powershell
winget install Freelensapp.Freelens
```

See: <https://winstall.app/apps/Freelensapp.Freelens>
